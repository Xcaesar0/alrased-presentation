# Alrased source audit
Source: Figma 3W0jyQdZmXYmiqYjGd9ccq. Inspected UX Study (11 boards), Design Screens (49 top-level screens/notes; 47 exported visual frames).
Product: human-led job-search service supported by digital transparency. User describes goals and preferences; advisor reviews, searches, curates, explains, receives feedback, follows up. Professional services are optional and coordinated through the same journey.
Audit: unpublished prototype, not a launched product. Findings include inconsistent 3/6/5-step explanations, account/payment ambiguity, disconnected additional services and unclear post-request visibility. Needs/personas/JTBD are hypotheses, not validated field research. No post-launch metrics.
Final onboarding: six steps (goal; location/work mode; CV or manual experience; preferences; optional services; review), then confirmation. Mobile review frame name says step 5 but actual content correctly says 6. Component-board mobile example still says 5; do not use it as canonical step count.
Canonical opportunity detail: 2098:32, verified content and render; current final version. Advisor explanation before job description. Actual state siblings cover interested, applied, interview, rejection and clarification; mobile bottom sheets differ structurally.
Dashboard: active search/new opportunity; action required; no opportunities; no professional services. Follow-up: active, action required, waiting for Alrased, active service, start. Distinguish responsibility, next action, last update.
Manager: workload, overdue tasks, unassigned clients, follow-up and allocation. Employee: ordered tasks, assigned clients, timer, attention and next work. AI Search entry on client rows; no actual search workflow designed or implemented.
System: Alexandria; purple #8B3AE5; dark #6B2F9A; warm #F6F4EF; ink #181535; cyan #00D3DD; magenta #F71DA5; controlled accent gradient. RTL right sidebar, mobile bottom nav, right-start progress, persistent primary action.
Honesty: homepage testimonials explicitly fictional. Package amounts present in source, not validated current offers. Names, counters, job listings, dates and advisor photos sample. Mobile beginning follow-up contains 24-hour promise conflicting with unresolved timing notes; do not present as service commitment. Account/payment order, who submits applications, service scope and response timing remain open. No original Jobzed screenshots found among full file top-level inventory; explain before state using audit findings, not fabricated UI.
Narrative: problem -> service model -> strategy/journey -> substantial homepage -> full onboarding -> current state -> curation/reasoning/decision -> follow-up/services -> mobile -> system -> operations -> future -> ecosystem/value -> before-after -> minimal close.
